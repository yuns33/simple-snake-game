# 贪吃蛇小游戏 (Simple Snake Game)

一个纯前端的经典贪吃蛇网页小游戏，无需任何框架或安装，直接打开 `index.html` 即可游玩。

## 功能特点

- 经典蛇身移动与吃食物逻辑
- 得分与本地最高分记录（localStorage）
- 键盘（方向键 / WASD）+ 手机触摸滑动控制
- 响应式画布，适配手机与桌面
- 霓虹风格界面，流畅动画

## 如何运行

1. 下载本仓库或克隆
2. 直接用浏览器打开 `index.html`
3. 或使用任意静态服务器：

```bash
# 例如用 Python
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 部署到 GitHub Pages

1. 仓库 Settings → Pages
2. Source 选择 Deploy from a branch
3. Branch 选 main，文件夹选 / (root)
4. 保存后几分钟即可访问：https://yuns33.github.io/simple-snake-game/

## 操作说明

| 设备 | 操作 |
|------|------|
| 电脑 | 方向键 或 W A S D |
| 手机 | 在画布上滑动 |

点击「开始游戏」或直接按方向键开始。
